# javascript-lotto-precourse

## 기능 정의

- "구입금액을 입력해 주세요." 출력 기능
- 로또 구입 금액 입력 기능(1,000원 단위로 입력 받으며 나누어 떨어지지 않는 경우 예외 처리한다.)
- 발행한 로또 수량 및 번호를 출력한다(오름차순 정렬)
- "당첨 번호를 입력해 주세요." 출력 기능
- 당첨 번호 입력 기능(쉼표(,)를 기준으로 구분하고 6가지의 숫자를 가져야 한다 또한 중복된 숫자가 존재해서는 안된다, 1~45 숫자만 입력 가능)
- "보너스 번호를 입력해 주세요." 출력 기능
- 보너스 번호 입력 기능(단 하나의 1~45 숫자만 입력 가능, 당첨 번호와 중복 불가능)
- 당첨 내역과 수익률 출력 기능(수익률은 소수점 둘째 자리에서 반올림)
